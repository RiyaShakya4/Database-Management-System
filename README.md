# Database Management System

## Project Description

This project demonstrates the design and management of relational databases using MySQL. The project focuses on creating tables, defining relationships, applying constraints, and using SQL queries to manage information.

The project helped me understand how databases store, organize, update, and retrieve data efficiently.

## Main Features

* Database creation
* Table creation
* Primary keys
* Foreign keys
* Unique constraints
* NOT NULL constraints
* CHECK constraints
* Relationships between tables
* INSERT operations
* UPDATE operations
* DELETE operations
* SELECT queries
* JOIN queries
* Subqueries

## Project Purpose

The purpose of this project is to understand the basic concepts of database management and relational database design. It provides practical experience with MySQL and SQL commands.

## Technologies

* MySQL
* SQL
* MySQL Workbench
* GitHub

## Database Concepts

The project covers important database concepts such as:

* Relational database design
* Primary and foreign keys
* Data integrity
* Constraints
* Normalization
* SQL queries
* Table relationships

## Project Structure

The project contains SQL scripts for creating databases and tables, inserting data, modifying records, and retrieving information using different SQL queries.

## Future Improvements

Future improvements may include developing a web-based interface, connecting the database to an application, adding user authentication, and implementing more advanced database operations.
